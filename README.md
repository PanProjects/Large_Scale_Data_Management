## Περιγραφή

Σκοπός της εργασίας είναι η ανάλυση σε (μεγάλα) σύνολα δεδομένων με τεχνικές επεξεργασίας που εφαρμόζονται σε data science projects. Τα εργαλεία που χρησιμοποιούνται είναι **Apache Hadoop** (version ≥ 3.0) και **Apache Spark** (version ≥ 3.5), πάνω στους πόρους του ειδικά διαμορφωμένου εργαστηριακού περιβάλλοντος.

Στόχοι της εργασίας:

- Εξοικείωση και ανάπτυξη δεξιοτήτων στην εγκατάσταση και διαχείριση των κατανεμημένων συστημάτων Apache Spark και Apache Hadoop.
- Χρήση σύγχρονων τεχνικών μέσω των API του Spark για ανάλυση δεδομένων όγκου.
- Κατανόηση των δυνατοτήτων και περιορισμών των εργαλείων σε σχέση με τους διαθέσιμους πόρους και τις επιλεγμένες ρυθμίσεις.

## Δεδομένα

Τα δεδομένα είναι διαθέσιμα μέσα στο HDFS κάτω από το directory:

```
hdfs://hdfs-namenode.default.svc.cluster.local:9000/data/
```

| Σύνολο Δεδομένων | Τοποθεσία στο HDFS |
| --- | --- |
| Los Angeles Crime Data (2010-2019) | `/data/LA_Crime_Data/LA_Crime_Data_2010_2019.csv` |
| Los Angeles Crime Data (2020-2025) | `/data/LA_Crime_Data/LA_Crime_Data_2020_2025.csv` |
| Census Blocks | `/data/LA_Census_Blocks_2020.geojson` |
| Census Blocks Fields | `/data/LA_Census_Blocks_2020_fields.csv` |
| Median Household Income by Zip Code | `/data/LA_income_2021.csv` |
| LA Police Stations | `/data/LA_Police_Stations.csv` |

**Λεπτομέρειες:**

- **Los Angeles Crime Data**: Από το δημόσιο αποθετήριο δεδομένων της κυβέρνησης των ΗΠΑ. Καταγραφές εγκλημάτων για την πόλη του Los Angeles, 2010-2025, σε δύο μέρη (2010-2019, 2020-2025). Περιγραφές πεδίων στους αντίστοιχους συνδέσμους.
- **Census Blocks (Los Angeles County)**: Απογραφικά στοιχεία της Κομητείας του Los Angeles για το 2020 σε μορφή GeoJSON. Συνοδεύεται από αρχείο περιγραφών πεδίων (*Census Blocks Fields*).
- **Median Household Income by Zip Code (Los Angeles County)**: Μέσο εισόδημα ανά νοικοκυριό για κάθε ZIP Code της Κομητείας, στατιστικά του 2021. Αποθηκευμένο σε CSV με delimiter τον χαρακτήρα `;`.
- **LA Police Stations**: Τοποθεσίες των 21 αστυνομικών τμημάτων της πόλης του Los Angeles.

## Ερωτήματα (Queries)

### Query 1
Ταξινόμηση, σε φθίνουσα σειρά, των τμημάτων της ημέρας ανάλογα με το ποσοστό καταγραφών εγκλημάτων (επί του συνόλου) που έλαβαν χώρα στο δρόμο (`STREET`). Τμήματα της ημέρας:

| Τμήμα | Ώρες |
| --- | --- |
| Πρωί | 5:00πμ - 11:59πμ |
| Απόγευμα | 12:00μμ - 4:59μμ |
| Βράδυ | 5:00μμ - 8:59μμ |
| Νύχτα | 9:00μμ - 4:59πμ |

### Query 2
Εύρεση, για κάθε έτος, των 3 μηνών με τον υψηλότερο αριθμό καταγεγραμμένων εγκλημάτων. Εκτύπωση ανά έτος: οι συγκεκριμένοι μήνες, ο συνολικός αριθμός περιστατικών και η θέση (ranking) του μήνα στην κατάταξη του έτους. Αποτελέσματα σε αύξουσα σειρά ως προς το έτος και φθίνουσα ως προς αριθμό καταγραφών/κατάταξη.

Παράδειγμα μορφής αποτελέσματος:

| year | month | crime_total | ranking |
| --- | --- | --- | --- |
| 2010 | 2 | 2145 | 1 |
| 2010 | 3 | 1492 | 2 |
| 2010 | 5 | 54 | 3 |
| 2011 | 12 | 4632 | 1 |
| ... | ... | ... | ... |

### Query 3
Με αναφορά τα δεδομένα της απογραφής 2020 (πληθυσμός) και της απογραφής 2021 (εισόδημα ανά νοικοκυριό), υπολογισμός για κάθε ZIP Code του Los Angeles του μέσου ετήσιου κατά κεφαλήν εισοδήματος για τη διετία 2020-2021.

### Query 4
Υπολογισμός, ανά αστυνομικό τμήμα, του αριθμού εγκλημάτων που έλαβαν χώρα πλησιέστερα σε αυτό από οποιοδήποτε άλλο, καθώς και της μέσης απόστασής του από τις τοποθεσίες των περιστατικών. Αποτελέσματα ταξινομημένα κατά αριθμό περιστατικών σε φθίνουσα σειρά.

Παράδειγμα μορφής αποτελέσματος:

| division | average_distance | # |
| --- | --- | --- |
| 77TH STREET | 2.208 | 7045 |
| RAMPART | 2.009 | 4595 |
| FOOTHILL | 3.597 | 3047 |
| PACIFIC | 2.739 | 2132 |

## Ζητούμενα

1. **Φορμάτ δεδομένων.** Τα δεδομένα είναι κυρίως σε CSV. Είναι το καταλληλότερο φορμάτ για επεξεργασία από το Spark; Ποια εναλλακτικά φορμάτ γνωρίζετε και σε τι διαφέρουν; Επιλέξτε ένα, μετατρέψτε τα δεδομένα σε αυτό και συγκρίνετε τη διαφορά στην επίδοση (χρόνο εκτέλεσης) σε σχέση με το CSV για κάποιο από τα Queries.

2. **Query 1 - DataFrame (με & χωρίς UDF) και RDD APIs.** Εκτέλεση και των τριών υλοποιήσεων με **2 executors (1 core, 2GB memory)**. Υπάρχει διαφορά στην επίδοση; Σχολιασμός των ευρημάτων.

3. **Query 2 - DataFrame και SQL APIs.** Εκτέλεση και των δύο υλοποιήσεων με **4 executors (1 core, 2GB memory)**. Σύγκριση και σχολιασμός των χρόνων εκτέλεσης.

4. **Query 3 - DataFrame και RDD APIs** *(20%)*. Εκτέλεση και των δύο υλοποιήσεων με **3 executors (1 core, 2GB memory)**. Σύγκριση και σχολιασμός των χρόνων εκτέλεσης.

5. **Query 4 - DataFrame ή SQL API** *(20%)*. Για τα joins, αναφορά των στρατηγικών που επιλέγει ο optimizer του Spark και σχολιασμός των επιλογών του. Για μελέτη κάθετης και οριζόντιας κλιμακωσιμότητας, εκτέλεση της υλοποίησης:

   **A. Σε 2 executors, με configurations:**
   - 1 core, 2 GB memory
   - 2 cores, 4 GB memory
   - 4 cores, 8 GB memory

   **B. Με συνολικούς πόρους 8 cores / 16 GB μνήμης, με configurations:**
   - 2 executors × 4 cores, 8 GB memory
   - 4 executors × 2 cores, 4 GB memory
   - 8 executors × 1 core, 2 GB memory

   Σχολιασμός αποτελεσμάτων.

6. **Στρατηγικές Join (Query 3 DataFrame API & Query 4).** Χρήση των μεθόδων `hint` και `explain` για εύρεση των στρατηγικών join του catalyst optimizer. Πειραματισμός με διαφορετικές στρατηγικές (`BROADCAST`, `MERGE`, `SHUFFLE_HASH`, `SHUFFLE_REPLICATE_NL`) και σχολιασμός της επίδρασης στην επίδοση. Ποια(ες) στρατηγική(ές) είναι καταλληλότερη(ες) και γιατί;
